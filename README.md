# DiskSpace

드라이브나 폴더 안의 용량 분포를 **트리맵(treemap)** 으로 한눈에 보여 주는 Windows 데스크톱 프로그램입니다.
폴더와 파일이 차지하는 크기에 비례하는 사각형으로 그려지므로, 어디에서 디스크 공간이 많이 쓰이는지 바로 찾을 수 있습니다.

- 플랫폼: Windows 10/11
- 개발 환경: Visual Studio 2022, .NET 9.0, Windows Forms

## 주요 기능

### 드라이브 / 폴더 선택
- 실행하면 사용 가능한 드라이브가 아이콘으로 나열되는 선택 창이 열립니다.
- 드라이브 아이콘에 마우스를 올리면 파일 시스템, 드라이브 종류, 사용 용량 / 전체 용량이 툴팁으로 표시됩니다.
- 아이콘을 더블클릭하거나, `Path` 입력란에 경로를 직접 입력하거나, `...` 버튼으로 폴더를 골라 스캔을 시작합니다.
- 명령줄 인수로 경로를 넘기면 선택 창 없이 바로 스캔합니다.

  ```
  DiskSpace.exe D:\Projects
  ```

### 병렬 스캔
- **CPU 논리 코어 수만큼 작업 스레드**를 만들어 디렉터리를 병렬로 탐색합니다. 디렉터리는 공유 작업 스택에 쌓이고, 쉬는 스레드가 다음 디렉터리를 가져가 처리합니다.
- 스캔 스레드는 낮은 우선순위로 실행되어 다른 작업을 방해하지 않습니다.
- 숨김 파일과 시스템 파일(`pagefile.sys`, `hiberfil.sys` 등)도 포함합니다.
- 정션과 심볼릭 링크(reparse point)는 따라가지 않아, 같은 데이터를 두 번 세거나 순환에 빠지지 않습니다.
- 희소(sparse) 파일은 논리 크기가 아니라 **실제 할당된 크기**로 계산합니다(VM 디스크, WSL `vhdx` 등).
- 64 KB 미만의 작은 파일과 폴더당 상위 256개를 넘는 파일은 `[N files]` 하나로 묶어 메모리 사용량을 줄입니다.

### 진행 상황 표시
- 제목 표시줄에 `DiskSpace - [C:\] - full scan 42%` 형식으로 진행률을 표시합니다.
  - 드라이브 전체를 스캔할 때는 드라이브의 사용 용량 대비 지금까지 찾은 용량으로 계산합니다.
  - 일반 폴더를 스캔할 때는 찾은 폴더 수 대비 탐색을 마친 폴더 수로 계산합니다.
- 상태 표시줄에 상태(스캔 중 / 완료 / 취소됨), 탐색한 폴더 수 / 찾은 폴더 수, 파일 수, 전체 크기, 스레드 수, 경과 시간과 진행 막대가 표시됩니다.
- 트리맵은 스캔하는 동안 0.5초마다 갱신되어, 결과가 채워지는 과정을 바로 볼 수 있습니다.

### 트리맵 보기
- squarified 트리맵 알고리즘(Bruls, Huizing, van Wijk)으로 각 사각형을 정사각형에 가깝게 배치해 크기를 비교하기 쉽습니다.
- 폴더 안에 하위 폴더와 파일이 중첩되어 그려지고, 폴더 머리글에는 이름과 크기가 표시됩니다.
- 폴더는 갈색 계열(깊이마다 색조가 조금씩 다름), 파일은 파란색, 묶인 작은 파일은 옅은 파란색으로 그립니다.
- 아직 스캔하지 않은 폴더는 빗금 무늬로 표시됩니다.
- 사각형에 마우스를 올리면 상태 표시줄에 전체 경로, 크기, 현재 보기에서 차지하는 비율이 표시됩니다.

### 탐색
| 동작 | 방법 |
| --- | --- |
| 폴더로 확대 | 폴더 사각형 왼쪽 클릭 |
| 상위 폴더 | 현재 루트(맨 위 머리글) 클릭, `Alt+↑`, 툴바 `▲ 상위 폴더` |
| 뒤로 / 앞으로 | `Backspace`, `Alt+←` / `Alt+→`, 마우스 뒤로/앞으로 버튼 |
| 스캔 루트로 이동 | `Alt+Home`, 툴바 `⌂ 루트` |

오른쪽 클릭 메뉴에서는 **탐색기에서 열기**(파일이면 해당 파일 선택), **이 폴더로 확대**, **경로 복사**, **상위 폴더** 를 사용할 수 있습니다.

### 스캔 관리
| 기능 | 단축키 / 위치 |
| --- | --- |
| 새 스캔 (드라이브/폴더 다시 선택) | `Ctrl+N`, 툴바 `📂 새 스캔` |
| 스캔 취소 | `Esc`, 스캔 중에는 툴바 버튼이 `✖ 취소`로 바뀜 |
| 다시 스캔 | `F5`, 툴바 `⟳ 다시 스캔` |
| 휴지통 비우기 후 다시 스캔 | 툴바 `🗑 휴지통 비우기`, 파일 메뉴 |

- **휴지통 비우기**는 모든 드라이브 휴지통의 항목 수와 크기를 보여 주고 확인을 받은 뒤 비웁니다. 되돌릴 수 없으므로 기본 선택은 `아니요`입니다.

### 접근 거부 폴더 목록
- 권한 문제로 열지 못한 폴더가 있으면 툴바 오른쪽에 `⚠ 오류: N개` 버튼이 나타납니다.
- 버튼을 누르면 해당 폴더 목록을 임시 텍스트 파일로 저장해 메모장으로 엽니다. 스캔 중에도 지금까지의 목록을 볼 수 있습니다.
- 시스템 폴더까지 모두 집계하려면 관리자 권한으로 실행하세요.

### 고해상도(DPI) 지원
- **PerMonitorV2** DPI 인식으로 동작합니다.
- 배율이 다른 모니터로 창을 옮기거나 배율 설정을 바꾸면 창 크기, 여백, 아이콘, 글꼴을 새 DPI에 맞게 다시 계산합니다. 여러 번 바뀌어도 레이아웃이 어긋나지 않도록 모든 크기를 96 DPI 기준값에서 매번 새로 계산합니다.

## 빌드 및 실행

필요 사항: [.NET 9 SDK](https://dotnet.microsoft.com/download) (또는 Visual Studio 2022 17.12 이상)

```powershell
# 빌드
dotnet build DiskSpace.sln -c Release

# 실행
dotnet run --project src/DiskSpace
```

Visual Studio에서는 `DiskSpace.sln`을 열고 `F5`로 실행합니다.

## 프로젝트 구조

```
DiskSpace.sln
src/DiskSpace/
├── Program.cs          진입점. 명령줄 인수 또는 드라이브 선택 창으로 경로를 정함
├── DriveSelectForm.cs  드라이브 선택 / 경로 입력 창
├── MainForm.cs         메인 창: 메뉴, 툴바, 상태 표시줄, 탐색 기록, 진행률 표시
├── Scanner.cs          파일 트리 모델(Node, DirNode, FileNode)과 병렬 스캐너
├── TreemapView.cs      squarified 트리맵을 그리는 컨트롤
├── NativeMethods.cs    Win32 호출: 셸 아이콘, 할당 크기, 휴지통 조회/비우기 등
├── Dpi.cs              96 DPI 기준 크기를 현재 DPI로 변환
├── SizeFormat.cs       바이트 수를 KB/MB/GB 문자열로 변환
├── AppIcon.cs          내장된 앱 아이콘 로드
└── app.ico             앱 아이콘
tools/
└── make_icon.ps1       app.ico를 생성하는 PowerShell 스크립트
```
